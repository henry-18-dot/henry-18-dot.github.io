为我的刷书应用 TokTok 编写三份独立的 ChatGPT 项目约定：《为什么伟大不能被计划》《人的境况》《百年孤独》。

你只编写项目约定，不生成章节正文。我会把对应书籍 Markdown 上传为项目源，再在同一项目中开多个对话，分别说“讲第一章”“讲第二章”。

每份约定应能直接贴进项目设置，明确书籍范围、真实章节结构、固定术语、每章应保留的论证与事件、叙述方式、分页方法、图表类型及逐章完成标准。

输出使用 Markdown，固定为：

```markdown
# 第N章 原标题
## 本章概述
正文概述
---
## 页面标题
这一页的正文
---
按需要继续分页
## 沉淀问题
- 一个具体、值得追问的问题
```

每页围绕一个可理解的内容单元，不为控制字数删掉关键论证。可使用比较表、时间线、人物关系图、公式和短引用。原文出处保留章节及可定位信息，关联人物、书籍、事件和概念使用统一名称。

正文用自然中文，不写“三句话讲清”、分号串句、“不是……而是……”和重复总结。标题组织内容，不包装价值判断。解释具体矛盾和因果，不套固定三点模板。

- 《为什么伟大不能被计划》：11章。先说明搜索机制与实验，再处理社会应用，区分实验结果与作者推论。
- 《人的境况》：6章45节。保留两级结构，固定劳动、工作、行动等术语，不改写成职场指南。
- 《百年孤独》：20个无标题章节。使用原章号，按当前章控制剧透，区分同名人物，保留叙述顺序与事件顺序的差别。

历史评价需另列出处，只采用能核对的原始资料。不要生成作家模拟评论、虚拟热度或实时推荐问题，这些由应用处理。

分别输出三份完整项目约定，避免复制同一套文案只换书名。
